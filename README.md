Gomule Fork
======

Gomule author: silospen (https://github.com/GoMule/GoMule)

This fork contributor: The Dude



### 1. Brief Description
---------------------------
  Gomule fork of the original Gomule.

  Main differences:

  * different layout of shared stash

  * material stash is displayed, but not possible to interact with items

  * item graphics have color tints as in game

  * secondary sorting by name in stash item list

  * some other minor tweaks


### 2. Requirements
---------------------------
  Java runtime.



### 3. Installation
---------------------------
  * Just unzip the package. On windows launch the jar or use the gomule-run.bat


### 4. Compile from sources
---------------------------
  * Install Java and Java SE Development Kit 25.0.2 or higher, e.g. from https://www.oracle.com/europe/java/technologies/downloads/

  * Run 'gradlew.bat' - this will prepare packages for compilation

  * Run 'gradlew.bat jar' - this will compile gomule and output jar file
